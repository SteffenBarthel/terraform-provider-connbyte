# ConnByte Provider

The ConnByte provider manages DNS records for domains hosted at [ConnByte](https://connbyte.com/).
It talks to the ConnByte API (`https://api.connbyte.com`).

Works with Terraform and [OpenTofu](https://opentofu.org/).

## Authentication

Create an API token in your [ConnByte](https://connbyte.com/) account. Pass it with `api_token`
or the `CONNBYTE_API_TOKEN` environment variable. Do not commit the token to version control.

## Example Usage

```terraform
terraform {
  required_providers {
    connbyte = {
      source = "SteffenBarthel/connbyte"
    }
  }
}

# The API token can also be set with the CONNBYTE_API_TOKEN environment variable.
provider "connbyte" {
  api_token = var.connbyte_api_token
}

variable "connbyte_api_token" {
  type      = string
  sensitive = true
}
```
